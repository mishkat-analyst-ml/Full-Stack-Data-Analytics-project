# Full-Stack-Data-Analytics-project

End-to-End Full Stack Data Analytics Project

# 📊 Project Overview

A complete end-to-end data analytics solution for Daraz e-commerce sales data, featuring Python-powered ETL, SQL-based business intelligence, and an interactive dashboard for executive decision-making.


This project demonstrates full-stack data engineering capabilities - from raw data processing to actionable business insights - following industry best practices used at top tech companies.

# 🌟 Key Features

# 🎯 Data Pipeline Architecture

ETL Pipeline: Automated data extraction, cleaning, and transformation


Outlier Detection: IQR-based anomaly detection for quality assurance


Feature Engineering: Derived business metrics (sales, time-based aggregations)


Data Quality: Comprehensive handling of missing values and duplicates


# 📈 Business Intelligence
Revenue Analytics: Year-over-Year (YoY), Month-over-Month (MoM), and Year-to-Date (YTD) tracking


Category Performance: Revenue breakdown by 7+ product categories


Geographic Insights: City-level revenue distribution analysis


Payment Analysis: Method preference and revenue contribution


# 📊 Interactive Dashboard

**KPI Cards:**  6 key business metrics at a glance


**Revenue Trends:** Monthly and yearly revenue visualizations

**Product Performance:** Top/Bottom performing products

**Customer Segmentation:** Tier-based customer classification (Premium, Gold, Regular)

# 🛠️ Technical Stack

Component	Technology

Data Processing	Python (Pandas, NumPy, Matplotlib)

Database	MySQL / SQL Workbench

Visualization	Matplotlib

Version Control	Git & GitHub

Development	Jupyter Notebook, VS Code
